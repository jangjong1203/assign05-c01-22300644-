CRUD Service

    구현한 서비스 주제
    영화정보 관리 서비스

    사용하는 데이터 Field
    id 영화고유번호
    title 제목
    director 감독
    genre 장르
    year 개봉연도
    rating 평점

    Create: 추가(add) 버튼 클릭시 각 입력창에 데이터가 맞게 입력됬는지 확인후 제대로 입력 되었다면 입력 된 값을 가져와서 배열에 맞게 변환후 배열에 push. 입력을 확인하는 요소: 입력창이 비어있는지 확인, rating이 0점이상 10이하 인지 확인+숫자인지 확인, 개봉연도가 숫자인지 확인.

    Read: 배열에 들어있는 값을 각각<td> 형식으로 저장 저장된값을 <tr>의 자식으로 추가해서 화면에 있는 표에 보이게한후 내용이 추가되어도 기존내용이 중복되지않게 불러온 값들을 비어있는값으로 초기화 forEach를 이용해 배열끝까지 반복. 

    Update: 수정 버튼을 추가후 수정버튼을 누른아이디를 저장할 변수를 추가. 수정을 누르면 추가 버튼을 저장 버튼으로 변경, 입력창에 수정을 누른 배열의 내용이 뜨도록하고 뜬 내용을 고치고 저장을 누르면 변경된 내용대로 배열에 수정되어 저장. 저장버튼도 다시 추가 버튼으로 변경.
     
    Delete: 삭제 버튼을 누르면 삭제확인 메세지가 뜨고 거기서도 '네'(true)를 누르면 배열에 있는 변수의 id들과 현재 삭제버튼을 누른 배열의 변수의id를 비교해서 삭제를 누른 배열의 위치를 확인후 위치를 이용해 배열에서 삭제.
    


JavaScript

    이번 과제에서 사용한 주요 JavaScript 기능을 설명합니다.
    console.log: 브라우저 도구에서 콘솔창에 값이나 객체를 출력하게해줌.(create 에서 배열이 값이 들어갔는지 확인하기위해 사용)
    querySelector(): 괄호에 들어있는 요소중 제일 첫번째로 있는 요소를 가져온다.
    addEventListener(): 특정 동작이 발동 되었을때 지정한 함수와 연결시켜주는 기능.
    createElement(): 전달받은 HTML요소개체를 생성 한다.
    appendChild(): 전달받은 요소를 부모요소의 마지막에 자식으로 붙인다.
    Array: 여러데이터를 주소 순서대로 저장하고 하나의 변수로 관리할수있게해준다. 
    splice: 배열의 요소를 삭제한다.
    findIndex: 배열의 요소를 찾아 주소를 반환한다.
    isNaN: 전달받은 값이 숫자가 아닌지 반환한다.(true면 숫자가 아니다.)
AI / Search Usage

    GEMINI를 사용했습니다.

    splice,findIndex 등 배열에서 삭제하기위한 기능을 구현하기위해 삭제할 array의 위치를 찾는방법,
    삭제하는방법에 대해 사용하였습니다.

    삭제버튼을 누르게 수락까지 누른다면, findIndex를 통해 moives배열 에서 현재 삭제 버튼을 누른 ID와 동일 한 ID
    를 가진 배열 요소를 찾아내어 주소를 반환시켜 변수에 저장합니다. 이후 splice를 이용해 배열에서 해당 요소를 삭제 했습니다.
    
    배열을 다루는 방법에 대해 알게 되었습니다. splice(위치, 갯수, 수정할것이 있다면 수정할 내용)처럼 위치는 배열의 몇번째에 위치했는지,
    갯수는 해당 위치부터 몇개의 데이터를 삭제할것인지(0을 입력하면 지워지지않음) , 수정할 내용은 삭제후 대체할 내용(안적으면 삭제만 됨).

Problem & Solution

    문제: 수정버튼을 누르고 바로 삭제를 누르면 저장버튼을 눌러야 정상적으로 추가버튼으로 돌아옴
    해결방법: 삭제버튼을 누르면 발동되는 함수에 수정버튼을 누르면 저장되는 현재 수정할 아이디와 삭제를 누른 저장되는 아이디와 같다면
    입력창을 비우고 버튼도 다시 추가로 바꾸고 수정할 아이디도 0으로 초기화시킴.
